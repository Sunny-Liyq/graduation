研究背景与核心挑战

语音伪造：身份冒充与欺诈

少量语音样本即可重建音色，电话诈骗、身份冒充和隐私泄露风险显著增加。

视频伪造：面部操控与演进

生成模型持续提升面部替换、表情迁移与细节重建质量，传统伪影逐渐减弱。

多模态伪造：跨模态语义一致

音唇同步、语义耦合和视觉真实性共同增强，使单模态检测方案更容易失效。

三类核心检测挑战

泛化不足跨语言、跨设备、跨数据集和噪声环境下性能易衰减。
伪影弱化高质量生成内容减少可见伪影，压缩也会破坏原始痕迹。
一致性缺失音视频间深层语义关联和时间同步关系难以稳定捕捉。

主要研究工作与方法创新

频谱增强匿名语音攻击评测

问题核心：语音匿名化系统缺乏高强度、深层次的安全评测机制。

核心方法：Wav2Vec 2.0 结合频谱调整数据增强。

EER 降低 > 30%（ICASSP 2025）

生物启发式选择性特征网络

问题核心：视频伪造检测面临跨数据集泛化能力不足。

核心方法：SFE-Net 动态激活光照、频域、压缩、结构与纹理特征。

跨数据集 AUC 79.5%（ICASSP 2025）

多模态大模型音视频联合检测

问题核心：复杂伪造中模态间时序与语义不一致性难以捕捉。

核心方法：AV-LMMDetect 基于 Qwen 2.5 Omni 两阶段监督微调。

FakeAVCeleb AUC 99.2%（ICASSP 2026）

双因素级联验证物理系统

问题核心：纯软件防御易被绕过，缺乏身份与真伪的一体化验证。

核心方法：ASV（ECAPA-TDNN）+ ADD 级联，硬件端侧物理级防护。

防护等级 物理级安全（发明专利初审合格）

工作四：语音安全系统问题

现有问题

软件算法可能被绕过，难以提供端到端安全链路。
单一 ASV 或 ADD 功能不足以覆盖身份冒充与合成攻击。
边缘设备部署受计算资源和功耗限制。
身份合法且语音真实才允许通过 系统设计目标是把“谁在说”和“是不是人真实说”两个问题串联起来，堵住未授权用户和合成语音两类攻击入口。
组件功能安全价值
ASV 模块自动识别说话人身份判断“是谁在说”，防止未授权用户访问
ADD 模块检测语音是否被伪造判断“是否为真实人声”，防止语音合成攻击
两者级联仅当身份匹配且语音真实时允许通过构建“双因素语音验证”，提升抗伪造能力

全文总结

工作一：匿名语音安全评测

从攻击视角评估匿名语音身份残留，说明隐私保护系统需要面对更强的自监督语音表示攻击。

工作三：音视频联合检测

将视频、音频和检测问题统一输入多模态大模型，利用模态内伪影和模态间一致性完成判别。

工作四：语音安全系统

把身份认证和深度伪造检测级联到语音采集前端，形成面向实际入口的双因素防护流程。
