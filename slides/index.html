理论基础（三）：伪造生成与检测原理

论文第 2.3 节

本节从生成和检测两个角度解释深度伪造问题：GAN 与扩散模型提升生成质量，也在生物一致性、频率域、压缩重建、时序一致性和音视频同步等方面留下可检测线索。

  • GAN 通过生成器与判别器对抗训练生成伪造样本。

  • 音视频联合伪造还需要分析口型、声音和表情之间的同步关系。

工作一：语音匿名化安全评测问题

研究问题

匿名语音在可懂度保持的同时，是否仍在高维表示空间中保留说话人相关信息？

传统 MFCC、i-vector、x-vector 对复杂匿名扰动敏感性有限。
Wav2Vec 2.0、HuBERT 等自监督模型学习到更深层的语音表示。
需要更高强度攻击模型评估匿名化系统的安全边界。
成果对应 SpecWav-Attack: Leveraging Spectrogram Resizing and Wav2Vec 2.0 for Attacking Anonymized Speech，ICASSP 2025 第一作者；Voice attacker challenge 全球前五。
匿名处理不等于身份信息完全消除 本页要说明的问题不是“声音听起来是否改变”，而是匿名语音经过深层模型表示后，是否仍能被重新区分为不同说话人。

工作二：视频伪造检测问题

问题挑战

视频深度伪造痕迹存在多样性：光照、纹理、高频、压缩、形态等特征差异明显。

方法局限

固定特征提取难以适应多种伪造类型，限制跨数据集泛化能力。

目标

工作二：小结

设计思路

用生物启发式选择性表达解决固定特征范式自适应不足。

模型结构

五类特征提取 + 动态门控 + 特征融合 + LSTM 时序建模。

工作三：音视频联合伪造检测问题

单模态方法局限

仅分析音频或视频，忽略音唇同步、语义匹配和跨模态关联。
对抗者可能针对单一模态绕过检测。
传统底层特征缺少高层语义理解能力。

跨模态一致性线索

语义一致

音色与外观
时序关联
联合异常
音视频联合检测的关键不是把两个单模态分数相加，而是利用模型理解跨模态同步、语义和时序一致性；对应论文 Leveraging large multimodal models for audio-video deepfake detection: a pilot study，ICASSP 2026 共同第一作者。

工作三：Top-2 Token 预测策略

分类方式

最后位置 Logits
→
提取 Real / Fake
→
Softmax 概率
Real Token ID：12768
Fake Token ID：52317
当 p(Fake) > 0.5，判定为伪造。
把生成式回答压缩为稳定二分类 模型不需要生成长文本解释，只比较 Real 与 Fake 两个 token 的概率，降低生成随机性并提升推理效率。

判别规则

p(Fake) > 0.5 → Fake

该规则直接服务于音视频伪造检测的二分类目标。

全文总结

工作一：匿名语音安全评测

从攻击视角评估匿名语音身份残留，说明隐私保护系统需要面对更强的自监督语音表示攻击。

工作二：视频伪造检测

用差异特征选择机制融合多类伪造线索，提升跨数据集视频伪造检测的泛化能力。

工作三：音视频联合检测

将视频、音频和检测问题统一输入多模态大模型，利用模态内伪影和模态间一致性完成判别。

工作四：语音安全系统

把身份认证和深度伪造检测级联到语音采集前端，形成面向实际入口的双因素防护流程。
