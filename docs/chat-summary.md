# 幻灯片修改沟通记录摘要

本文档整理本轮沟通中适合进入 git 的关键约定、页面修改目标和后续维护规则。未保存原始聊天全文，避免写入个人路径、账号、SSH 配置等敏感信息。

## 全局约定

| 类别 | 约定 | 说明 |
| --- | --- | --- |
| 页码定位 | 用户提到的“第 X 页”均指 HTML 右下角显示的页码 | 不按文档 DOM 顺序或封面开始计数定位页面 |
| 图片展示 | 图片作为内容证据展示时只缩放、不裁剪 | 优先使用 `object-fit: contain`，保留完整图像内容 |
| 版式风格 | 统一蓝白学术答辩风格 | 白底、浅蓝面板、蓝色强调、细边框、8px 左右圆角 |
| 页脚总结 | 每页只保留一个底部总结条 | 优先使用 slide 的 `data-footer`，避免重复底部说明 |
| 图表编号 | 图和表按 HTML 出现顺序连续编号 | 图片用“图1、图2...”，表格用“表1、表2...” |
| 表格标题 | 每个表格上方必须有标题 | 标题使用蓝色加粗样式，避免和表格内容重叠 |
| 图标使用 | 用语义图标替代纯字母占位 | 如盾牌、麦克风、视频、网络节点、芯片等 |

## 后续维护检查表

| 检查项 | 通过标准 |
| --- | --- |
| 页码定位 | 修改前确认目标页的 `<span class="slide-number">` 或渲染右下角页码 |
| 图片 | 图片完整可见，没有裁剪、拉伸变形或明显空白失衡 |
| 表格 | 每个表都有上方标题，表号连续，文字不重叠 |
| 图号 | 新增或删除图片后，图号仍按出现顺序连续 |
| 版式 | 页面底部内容完整显示，不被页脚遮挡 |
| 风格 | 主色保持蓝白，不引入突兀深色块或多余配色 |
| 提交 | 只提交本次相关文件，避免把导出的 `dist/` 或临时文件混入 |
